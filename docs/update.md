# Update

기존 레코드를 선택해 특정 필드를 수정하는 기능.

## 동작

1. 수정할 레코드의 ID를 입력받는다.
2. `JsonRepository::findById(int id)`로 존재 여부를 확인한다.
   - 존재하지 않으면 "해당 ID의 데이터가 없습니다" 안내 후 메뉴로 돌아간다.
3. 존재하면 현재 값을 보여주고, 수정할 필드를 선택받는다 (예: `1) name 2) value`).
4. 새 값을 입력받는다 (빈 입력 시 기존 값 유지).
5. `JsonRepository::updateById(int id, ...)`로 인메모리 레코드를 갱신한다.
6. `JsonRepository::save()`로 즉시 JSON 파일에 반영한다.
7. 수정된 레코드 전체를 다시 출력해 결과를 확인시킨다.

## 입력 검증

- ID 파싱 실패, 필드 선택 범위 초과 시 재입력을 요구한다.

## 예외 처리

- 저장 실패 시 에러 메시지를 출력하고, 다음 저장 시도까지 인메모리 변경 사항이 유지됨을 안내한다.
- ID는 Update로는 변경할 수 없다 (ID는 자동 부여된 불변 식별자).
