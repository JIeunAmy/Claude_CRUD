# Delete

특정 레코드를 안전하게 삭제하는 기능.

## 동작

1. 삭제할 레코드의 ID를 입력받는다.
2. `JsonRepository::findById(int id)`로 존재 여부를 확인한다.
   - 존재하지 않으면 "해당 ID의 데이터가 없습니다" 안내 후 메뉴로 돌아간다.
3. 존재하면 해당 레코드의 전체 내용을 보여주고, 삭제 여부를 확인받는다 (`y/n`).
   - `n`(또는 그 외 응답) 입력 시 삭제를 취소하고 메뉴로 돌아간다.
4. `y` 확인 시 `JsonRepository::removeById(int id)`로 인메모리 벡터에서 레코드를 제거한다.
5. `JsonRepository::save()`로 즉시 JSON 파일에 반영한다.
6. 삭제 완료 메시지를 출력한다.

## 안전장치 ("안전하게 삭제")

- 삭제 전 항상 대상 레코드 내용을 보여주고 확인을 받는다 (되돌릴 수 없는 작업이므로).
- 존재하지 않는 ID에 대한 삭제 요청은 아무 것도 지우지 않고 안내만 한다.

## 입력 검증

- ID 파싱 실패 시 재입력을 요구한다.
- 확인 입력은 `y`/`n`(대소문자 무관) 외의 값은 재입력을 요구하거나 취소로 처리한다.

## 예외 처리

- 저장 실패 시 에러 메시지를 출력한다. 이 경우 인메모리에서는 이미 제거되었으므로, 다음 저장 성공 시까지 파일과 메모리 상태가 불일치할 수 있음을 사용자에게 안내한다.
