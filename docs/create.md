# Create

새로운 레코드를 입력받아 JSON 파일에 저장하는 기능.

## 동작

1. 콘솔에서 레코드의 각 필드 값을 입력받는다 (`Record`의 필드: 예) `name`, `value`).
2. `JsonRepository::add(Record)`를 호출한다.
   - ID는 사용자가 직접 입력하지 않고, 기존 레코드들의 최대 ID + 1로 자동 부여한다 (레코드가 없으면 1부터 시작).
   - 새 레코드를 인메모리 `std::vector<Record>`에 추가한다.
3. `JsonRepository::save()`를 호출해 변경된 전체 목록을 즉시 JSON 파일에 다시 쓴다.
4. 저장된 ID를 포함해 생성 결과를 콘솔에 출력한다.

## 입력 검증

- 필수 필드가 비어 있으면 재입력을 요구한다.
- 숫자 필드가 있는 경우 파싱 실패 시 재입력을 요구한다.

## 예외 처리

- 파일 쓰기 실패(`JsonValue::Save`가 `false` 반환) 시 에러 메시지를 출력하고, 메모리 상의 변경은 유지한 채 사용자에게 재시도 여부를 안내한다.
