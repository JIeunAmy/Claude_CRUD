# Read

저장된 레코드를 조회하는 기능. 전체 목록 조회와 ID/키 검색 두 가지 방식을 제공한다.

## 전체 목록 조회

1. `JsonRepository::getAll()`로 인메모리 `std::vector<Record>` 전체를 가져온다.
2. 레코드가 없으면 "데이터 없음" 안내를 출력한다.
3. 레코드가 있으면 ID를 포함해 각 필드를 콘솔에 표 형태(또는 줄 단위)로 출력한다.

## ID/키로 검색

1. 사용자로부터 조회할 ID(또는 키)를 입력받는다.
2. `JsonRepository::findById(int id)`를 호출한다.
   - `Object`는 벡터 기반이라 조회는 선형 탐색(O(n))이며, 현재 데이터 규모에서는 문제 없음.
3. 결과가 있으면 해당 레코드의 전체 필드를 출력한다.
4. 결과가 없으면 "해당 ID의 데이터가 없습니다" 안내를 출력하고 메뉴로 돌아간다.

## 입력 검증

- ID 입력이 숫자로 파싱되지 않으면 재입력을 요구한다.

## 예외 처리

- 조회는 파일을 다시 쓰지 않으므로 저장 실패 시나리오는 없다. 로드 시점(`JsonRepository::load()`)에서 발생한 `JsonParseError`는 앱 시작 단계에서 처리되며, Read 기능 자체는 이미 로드된 인메모리 데이터만을 사용한다.
